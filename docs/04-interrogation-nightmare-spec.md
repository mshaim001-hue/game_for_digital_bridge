# Спека #4 — «Допрос / Кошмар инспектора»

Статус: **актуальный концепт для стенда** (заменяет #3 «Сканер сигнала»)  
Аудитория: UX / art / dev  
Длительность сессии: **60–90 сек**

Логика вопросов и 8 исходов = прод-тест.  
Оболочка = сцена допроса + кошмар → пробуждение.

Связанные файлы: [05-character-bible-inspector.md](05-character-bible-inspector.md), [01-current-test-analysis.md](01-current-test-analysis.md)

---

## 1. Суть

Игрок попадает в **кошмарный допрос**: строгая инспекторша ведёт тот же тест, что на сайте.  
В конце — вердикт по дереву. Если обязанность есть — кошмар со штрафом/пеней/счетами.  
Потом **пробуждение** и QR: спокойствие покупается действием (подать декларацию), а не «убежать от налоговой».

Это **предупреждающий сон**, не симулятор уклонения.

---

## 2. Механика

| Слой | Что |
|------|-----|
| Ввод | Те же Да/Нет, чекбоксы, пункты активов |
| Дерево | Без изменений (q1_* / q2_* → 8 исходов) |
| Оболочка | Комната допроса, персонаж, лампа, реакции, 4 типа финала |
| «Температура допроса» | Опционально: лицо/тон инспектора жёстче на «горячих» ответах (не % Threat на UI) |
| Поражение процесса | Только выход до конца → «Допрос прерван» + 1 тап продолжить |

Правила этики:
1. Юридический исход = дерево, не сюжетная фантазия.  
2. Не награждать за «нет», не наказывать за «да».  
3. Штраф / пеня / блокировка счетов — **только** WATCH и ALERT.  
4. CLEAR и OUT — без ложного обвинения.

## 3. Сценарий по экранам

### E0 — Старт (реальность / тизер)
- Тёмный фон или край кровати / будильник (лёгкий намёк, что это сон — можно раскрыть только в конце).
- Заголовок: «Допрос» или «Тебе приснится это…»
- CTA: **«Начать допрос»** (не «Играть в налоги»)
- Мелко: «~1–2 мин · по мотивам реального теста»

### E1 — Комната допроса (установка)
- Стол, папка, **лампа в лицо игроку**, напротив — инспектор.
- Одна короткая реплика входа (см. библию).
- Сразу первый вопрос теста.

### E2 — Допрос = волны теста
Визуально те же 3 смысловые волны (прогресс можно показать папкой / штампами / главами дела):

1. **Резидент** — q1_1…  
2. **Обязательные** — q2_1, q2_2…  
3. **Активы / доходы** — q2_3…  

На каждый ответ — **микро-реакция** (0.3–0.8 сек): бровь, пометка в деле, «Хм.», штамп, усиление света лампы на «горячем» да.

Не растягивать катсцены: реплики короткие, вопросы читает она (можно слегка перефразировать тон, **смысл вопроса = прод**).

### E3 — Вердикт в кошмаре
По маппингу §6 → один из четырёх типов: ALERT / WATCH / CLEAR / OUT.  
Полные тексты реплик — в библии персонажа.

### E4 — Обрыв сна
- Резкий свет / звон будильника / лампа гаснет не в её пользу, а «мир ломается».
- 0.5–1.5 сек, без длинной анимации.

### E5 — Пробуждение + QR
- Спокойная комната (утро, телефон / листок с QR).
- Punchline зависит от финала (§6).
- CTA: QR + кнопка-дубль ссылки (на стенде QR обязателен).
- «Пройти допрос снова»

### E_ABORT
- «Допрос прерван — вердикт неполный»
- «Продолжить» / «Сначала»

---

## 4. Состояния игры

```
IDLE            → E0
INTERROGATION   → E1–E2 (волны W1/W2/W3 внутри)
VERDICT_DREAM   → E3
WAKE            → E4–E5
ABORTED         → E_ABORT
```

Clarity (внутренняя): 100% только в WAKE после полного дерева.  
Abort = неполный вердикт, без штрафа и без «вы чисты».

---

## 5. Маппинг 8 исходов → тип финала

| Код дерева | Тип финала | Кошмарный акцент |
|------------|------------|------------------|
| `r_not_resident` | **OUT** | Не ваш кейс, лампа гаснет |
| `r_none` | **CLEAR** | Жёсткий допрос, но «пока чисто» |
| `r_only270` | **WATCH** | Должны 270; намёк на последствия |
| `r_spouse_only270` | **WATCH** | то же |
| `r_spouse_no250` | **WATCH** | то же |
| `r_mandatory` | **ALERT** | 270+250; штраф / пеня / счета |
| `r_spouse_need250` | **ALERT** | то же |
| `r_both` | **ALERT** | то же |

Юридическая плашка под репликой = текст из прода (не искажать).  
Реплика инспектора = эмоциональная рамка.

## 6. Финалы — рамка для UX

### F_ALERT (жёсткий кошмар)
- Она: обязанность была → не подали → штраф, пеня, блокировка счетов (тональность угрозы сна).
- Пробуждение: **QR «Подай декларацию — и спи спокойно»**
- CTA жёсткий: услуга / консультант / InvesTax / CryptoTax

### F_WATCH (кошмар легче, тот же punchline)
- Она: сигнал на ФНО 270 (250 — по ситуации в юртексте).
- Те же последствия как предупреждение, чуть короче.
- Пробуждение: тот же QR «Подай… и спи спокойно»

### F_CLEAR
- Она: «Пока чисто. Но если появятся основания — мы ещё увидимся.»
- Пробуждение: мягкий QR / «Сохрани спокойствие» / AI-Zhan
- Без штрафа и блокировки

### F_OUT
- Она: «Вы не наш клиент по статусу.» Лампа гаснет.
- Пробуждение: без стыда; опционально «Если сомневаетесь — спросите»
- Без давления «подайте декларацию»

## 7. Визуальный тон (для art/UX)

- Стиль: **мультяшный / anime-inspired**, читаемый на стенде с 1–2 метров.
- Палитра допроса: тёмный стол, холодный свет лампы, тёплый акцент на лице инспектора.
- Пробуждение: светлая, тихая палитра (контраст к допросу).
- Персонаж: симпатичная + строгая; **без fanservice** (см. библию).
- Игрок: может быть силуэт / руки на столе / «ты» без детального лица (проще для стенда).

Motion (2–3 обязательных):
1. Пульс лампы / свет в лицо при «горячем» ответе  
2. Микро-реакция лица / штамп в деле  
3. Обрыв сна → резкая смена в утро

## 8. Что не трогать

- Порядок и условия вопросов  
- 8 юридических исходов и их смысл  
- Модалка «ответ меняет последующие вопросы» при назад  

## 9. Что катить вместо сканера

- E0–E5, персонаж, лампа, реакции  
- 4 рамки финала + QR на пробуждении  
- Abort-экран  

## 10. Критерии приёмки (для передачи UX → dev)

1. Любой путь = тот же юрисход, что прод-тест.  
2. Штраф/пеня/счета **не** показываются на CLEAR/OUT.  
3. WATCH/ALERT заканчиваются пробуждением + QR с punchline про сон.  
4. Сессия ~60–90 сек на типичном пути.  
5. Персонаж узнаваем в первом кадре допроса.

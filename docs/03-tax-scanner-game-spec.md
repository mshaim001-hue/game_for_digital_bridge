# Концепция #3 — «Сканер сигнала»
Спека для стенда · оболочка поверх существующего теста  
Источник логики: https://sber-invest.kz/services/taxreturn/test  
**Дерево вопросов и 8 юридических исходов не менять.**

---

## 1. Суть

Игрок не «играет в налоги» и не прячется от КГД.  
Он запускает **скан профиля**: факты о жизни → Threat Level → вердикт.

- **Ясность** = скан доведён до конца (процесс).
- **Threat** = насколько «горячий» найденный кейс (содержание).
- «Поймали» = система нашла основание для обязанности — **хороший** исход для продукта.

Длительность: **60–90 секунд**.

---

## 2. Механика (фиксировано)

| Слой | Что делает |
|------|------------|
| Оболочка | Радар, 3 волны, Threat Level, микро-фидбек, финальные бейджи |
| Дерево | Как в проде: ветки q1_* / q2_* без изменений |
| Ввод | Да/Нет, чекбоксы категорий, Да/Нет по пунктам активов — как сейчас |
| Таймер | Только атмосфера (опционально). **Нет геймовера по времени** |
| Поражение | Только если игрок **бросил скан** до финала |

### Threat Level

Шкала **0–100**, всегда видна сверху.

| Событие | Δ Threat | Примечание |
|---------|----------|------------|
| Старт скана | 0 | |
| Резидентство подтверждено (гражданин / 183 дня / центр интересов) | +10 | Волна 1 пройдена «внутри зоны» |
| Не резидент (три «нет») | 0, скан → OUT | Threat не поднимаем |
| Обязательная категория (сам) | +40 | Сразу путь к ALERT-зоне |
| Супруг(а) в категории | +25 | |
| Любой пункт «горячих» активов/доходов = да | +15 за пункт | Крипта, иностранный брокер, зарубежное имущество, самостоятельный доход, крупная сделка, долги за рубежом |
| ФНО 250 ещё не подавалась (когда вопрос задан) | +10 | Усиливает ALERT, не меняет дерево |
| Ответ «нет» / пункт не выбран | 0 | Честный «нет» не наказывается |

Кап: 100. Числа можно тюнить на стенде; **пороги финалов завязаны на юридический исход, не на Threat**.  
Threat — визуальный слой для зрителя; вердикт всегда из дерева.

### Micro-feedback (между шагами, 0.5–1.2 сек)

Короткие тосты, не блокируют ввод надолго:

- «Проверка резидентства…»
- «CRS / зарубежные сигналы…»
- «Форма 250 в истории…»
- «Основания для ФНО 270…»

Показывать только релевантные текущей волне / ответу.

## 3. Сценарий по экранам

### E0 — Старт
- Полноэкранный радар (пульс).
- Заголовок: «Сканер статуса декларирования»
- Подзаголовок: «Ответьте на вопросы — узнаем, есть ли сигнал для ФНО 250 / 270»
- CTA: **«Сканировать»** (не «Играть», не «Начать игру»)
- Мелко: «~1–2 минуты · данные никуда не отправляются» *(если это правда для стенда)*

### E1 — Волна 1 · Резидент
Прогресс: `●○○ Резидент`
- q1_1 гражданин?
- при необходимости q1_2 (183 дня), q1_3 (центр интересов)
- Interim (как сейчас): короткое подтверждение резидентства → дальше
- Если не резидент → сразу **F_OUT**

### E2 — Волна 2 · Обязательные
Прогресс: `●●○ Обязательные`
- q2_1 категории самого лица
- при «нет» → q2_2 категории супруга
- ветки q2_2_f250 / активы супруга — **без изменения порядка**

### E3 — Волна 3 · Активы / доходы
Прогресс: `●●● Активы`
- q2_3* чеклист оснований + при необходимости q2_3_f250
- Если волна 2 уже выдала финал (r_mandatory и т.п.) — волна 3 не показывается (как в дереве)

### E4 — Финал
См. §5. Один экран: бейдж + вердикт + CTA + «Сканировать снова».

### E_ABORT — Скан не завершён
Если уход / рестарт ветки / закрытие до результата:
- Заголовок: «Скан не завершён — вердикт неполный»
- Текст: «Без полного досье нельзя сказать, нужна ли декларация.»
- CTA: **«Продолжить скан»** (1 тап → тот же стейт) / «Начать заново»

---

## 4. Правила

1. **Юридическая истина > геймдизайн.** Исход = функция ответов по текущему дереву.
2. **Не награждать за «нет» и не штрафовать за «да».** Threat растёт от обнаруженных фактов, не от «ошибки игрока».
3. **Победа процесса** = ясность 100% (дошли до любого F_*).
4. **Поражение процесса** = только abort (E_ABORT).
5. **Эмоция «поймали вовремя»** — только на WATCH и ALERT (из концепции #1).
6. CLEAR и OUT — без охотничьего тона, без стыда.
7. Назад по ветке (если есть в UI): предупреждение как сейчас → при подтверждении можно считать **частичный abort** ясности (досье «сброшено»), Threat сбрасывается по новой ветке.
8. Шаринг / QR на стенде: на CLEAR — мягкий; на WATCH/ALERT — жёсткий CTA в услугу / AI-Zhan / заявку.

## 5. Состояния игры

```
IDLE          → E0, Threat=0, Clarity=0
SCANNING_W1   → волна Резидент
SCANNING_W2   → волна Обязательные
SCANNING_W3   → волна Активы
RESOLVED      → один из финалов F_*
ABORTED       → E_ABORT
```

### Clarity (внутренняя, можно не показывать отдельным баром)

- 0% в IDLE
- ~33% после завершения волны 1 (если ушли в W2)
- ~66% после волны 2 (если нужна W3)
- 100% при RESOLVED
- при ABORTED → «неполный», не показывать ложные 100%

Опционально на стенде: тонкое кольцо вокруг радара = Clarity; цвет заливки = Threat.

## 6. Маппинг 8 исходов → финалы

| Код дерева (прод) | Юридика (кратко) | Финал | Бейдж UI |
|-------------------|------------------|-------|----------|
| `r_not_resident` | не участник ВД | **OUT OF SCOPE** | OUT |
| `r_none` | оснований нет | **CLEAR** | CLEAR |
| `r_only270` | только 270 | **WATCH** | WATCH · 270 |
| `r_spouse_only270` | только 270 (супруг, 250 уже была) | **WATCH** | WATCH · 270 |
| `r_spouse_no250` | только 270 (супруг, зарубежных активов нет) | **WATCH** | WATCH · 270 |
| `r_mandatory` | 270 + 250 при необходимости | **ALERT** | ALERT · 270+250 |
| `r_spouse_need250` | 270 + 250 (зарубежные активы) | **ALERT** | ALERT · 270+250 |
| `r_both` | 270 + 250 | **ALERT** | ALERT · 270+250 |

Юридический текст вердикта = **как в текущем тесте** (не переписывать смысл).  
Меняется только **рамка** (бейдж + эмоция + CTA).

## 7. Финалы — копирайт оболочки

### F_CLEAR
- Бейдж: `CLEAR`
- Эмоция: спокойствие
- Заголовок: «Пока чисто»
- Подзаголовок: «Оснований для подачи в рамках всеобщего декларирования не видно.»
- *(ниже — штатный verdict из `r_none`)*
- CTA мягкий: «Сохранить статус» / QR на памятку или AI-Zhan
- Вторично: «Сканировать снова»

### F_WATCH
- Бейдж: `WATCH · ФНО 270`
- Эмоция из #1: поймали вовремя
- Заголовок: «Поймали вовремя. У тебя есть план»
- Подзаголовок: «Сигнал на ежегодную ФНО 270. ФНО 250 — по ситуации ниже.»
- *(штатный verdict из соответствующего r_*)*
- CTA жёсткий: «Подать со специалистом» / InvesTax / CryptoTax
- Вторично: AI-Zhan

### F_ALERT
- Бейдж: `ALERT · ФНО 270 + 250`
- Эмоция из #1: сильнее
- Заголовок: «Поймали вовремя. У тебя есть план»
- Подзаголовок: «Сильный сигнал: нужна и 270, и 250 (если ещё не сдавали).»
- *(штатный verdict)*
- CTA жёсткий: приоритет заявки консультанту
- Вторично: InvesTax / CryptoTax / AI-Zhan

### F_OUT
- Бейдж: `OUT OF SCOPE`
- Эмоция: нейтрально, без стыда
- Заголовок: «Не ваш кейс»
- Подзаголовок: «Вы вне всеобщего декларирования по статусу резидентства — в этой рамке декларация не нужна.»
- *(штатный verdict `r_not_resident`)*
- CTA мягкий: «Если сомневаетесь — спросите AI-Zhan»
- Без давления «подайте декларацию»

### F_ABORT (поражение процесса)
- Бейдж: нет / `INCOMPLETE`
- Заголовок: «Скан не завершён — вердикт неполный»
- CTA: «Продолжить скан» (1 тап) · «Начать заново»

## 8. Что на стенд катить / что не трогать

**Катить (оболочка):**
- E0 радар + «Сканировать»
- Прогресс трёх волн
- Threat Level сверху
- Micro-feedback
- Финальные рамки CLEAR / WATCH / ALERT / OUT / ABORT
- Копирайт эмоции «Поймали вовремя» только на WATCH/ALERT

**Не трогать:**
- Порядок и условия вопросов
- Формулы переходов case → next
- Смысл 8 юридических текстов
- Правило «ответ влияет на последующие вопросы» (модалка назад)

---

## 9. Критерии приёмки стенда

1. Любой путь по дереву даёт тот же юридический исход, что прод-тест.
2. До финала Threat виден и реагирует на «горячие» ответы.
3. Broсь сессии → E_ABORT, рестарт/продолжение за 1 тап.
4. WATCH/ALERT содержат фразу «Поймали вовремя. У тебя есть план» + жёсткий CTA.
5. CLEAR/OUT без охотничьего стыда.
6. Сессия укладывается в ~60–90 сек на типичном пути.

## Концепция 1 — «Инспектор на хвосте» (охота)

**Фантазия:** КГД-сканер идёт по следу. Каждый ответ — тишина или вспышка сигнала.

| Элемент | Как |
|---------|-----|
| Цель | Дойти до вердикта, пока дистанция не обнулится |
| Механика | Да/Нет и чеклисты как сейчас; полоска **Дистанция 100→0** |
| Риск | «Да» по основанию сокращает дистанцию; зарубежные активы = красный алерт |
| Напряжение | Пульс сканера, «перехваты» между секциями |
| Победа / поражение | Чист / Вне зоны = ушёл; 270 / 250+270 = поймали → «Поймали вовремя. У тебя есть план» + CTA |
| Время | 90–150 сек |

Плюс: сильная метафора. Минус: тонкий баланс тона (без «беги от налогов»).

---

## Концепция 2 — «Окно дедлайна» (гонка)

**Фантазия:** Не охотник, а часы. Классифицируешь себя до закрытия окна.

| Элемент | Как |
|---------|-----|
| Цель | Собрать полный статус-досье за ~2 минуты |
| Механика | Те же ветки; таймер-атмосфера + прогресс **Ясность 0–100%** |
| Риск | Не fail по времени, а **слепая зона**: пропуск ветки = неполный вердикт |
| Напряжение | Дедлайн + подсветка неясных зон (супруг? 250? зарубежка?) |
| Победа / поражение | Ясность 100% = победа (любой юридический исход); обрыв = «досье сорвано» |
| Время | 60–120 сек |

Плюс: этичнее, сильнее под конверсию. Минус: слабее мем «хищник».

## Концепция 3 — «Сканер сигнала» (2026 mobile) ← выбрано

**Фантазия:** Скан профиля как security/health app: радар, чипы фактов, вердикт одним экраном.

| Элемент | Как |
|---------|-----|
| Цель | 3 волны: **Резидент → Обязательные → Активы/доходы** |
| Механика | Да/Нет + чеклисты; UI плотнее; дерево то же |
| Риск | «Горячие» факты поднимают **Threat Level** |
| Напряжение | Threat + micro-feedback («CRS-матч», «форма 250 в истории») |
| Победа / поражение | CLEAR / WATCH (270) / ALERT (250+270) / OUT OF SCOPE; поражение только если бросил скан |
| Время | 60–90 сек |

Плюс: быстрый MVP, шаримый финал. Минус: меньше «истории», больше гаджета.

### Катить на стенд

1. Старт: радар + «Сканировать»  
2. Три волны как прогресс  
3. Threat Level сверху  
4. Финал: CLEAR / WATCH·ALERT («Поймали вовремя…») / OUT  
5. Abort → «Скан не завершён» + 1 тап

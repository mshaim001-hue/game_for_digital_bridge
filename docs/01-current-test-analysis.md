# Разбор текущего теста

Источник: https://sber-invest.kz/services/taxreturn/test  
Тип: ветвящийся квиз (decision tree), не игра.

## Структура UI

1. Гражданин / Резидент  
2. Основания  
3. Результат  

Ввод: Да/Нет, чекбоксы категорий, Да/Нет по пунктам активов.

---

## Секция 1 — резидент?

| Шаг | Вопрос | Дальше |
|-----|--------|--------|
| q1_1 | Гражданин РК? | Да → резидент → секция 2 |
| q1_2 | (если нет) >183 дня в РК? | Да → резидент → секция 2 |
| q1_3 | (если нет) центр жизненных интересов в РК? | Да → резидент; Нет → `r_not_resident` |

---

## Секция 2 — основания (только резиденты)

### q2_1 — обязательные категории (сам)

Госслужащий, руководитель ЮЛ, учредитель/акционер >10%, частный нотариус, ЧСИ, проф. медиатор.

- **Да** → `r_mandatory` (ФНО 270 ежегодно; 250 если ещё не подавалась)
- **Нет** → q2_2

### q2_2 — супруг(а) в категориях?

- **Да** → q2_2_f250 «Подавали ли ФНО 250 ранее?»
  - Уже подавали → `r_spouse_only270`
  - Не подавали → чеклист зарубежных активов (q2_2a/b/c)
    - Есть активы → `r_spouse_need250`
    - Нет → `r_spouse_no250`
- **Нет** → q2_3

### q2_3 — другие основания

- Доход, подлежащий самостоятельному налогообложению  
- Крупная сделка >20 000 МРП  
- Деньги за рубежом  
- Имущество за рубежом (вкл. иностранные ЦБ, крипта и т.д.)  
- Дебиторская / кредиторская задолженность за рубежом  

- Ничего → `r_none`  
- Что-то есть → q2_3_f250 «Уже подавали ФНО 250?»
  - Уже подавали → `r_only270`
  - Не подавали + есть зарубежные активы (c/d/e) → `r_both`
  - Не подавали + только доход/крупная сделка → `r_only270`

## 8 юридических исходов

| Код | Смысл |
|-----|--------|
| `r_not_resident` | Не резидент — декларация в рамках ВД не нужна |
| `r_none` | Оснований нет — подавать не нужно |
| `r_only270` | Только ФНО 270 |
| `r_spouse_only270` | Только ФНО 270 (супруг; 250 уже была) |
| `r_spouse_no250` | Только ФНО 270 (супруг; зарубежных активов нет) |
| `r_mandatory` | 270 + 250 при необходимости |
| `r_spouse_need250` | 270 + 250 (зарубежные активы) |
| `r_both` | 270 + 250 |

## Скрытая ось «поймают / не поймают»

Не уклонение, а **обнаружение обязанности**:

| Состояние | Смысл |
|-----------|--------|
| Вне зоны | не резидент |
| Чист | оснований нет |
| На радаре | только 270 |
| Полный захват | 270 + 250 |

## Дизайн-принцип для геймификации

Ответы — факты о жизни, не скилл.  
Нельзя награждать за «нет» и наказывать за «да».

- «Поймали» = нашли основание (хорошо для продукта: узнать раньше дедлайна)  
- «Ушёл» = оснований нет / вне юрисдикции  
- Напряжение — от обнаружения и темпа, не от сокрытия

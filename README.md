# Game for Digital Bridge — Сканер статуса декларирования

Геймификация теста «Нужно ли вам сдавать декларацию?»  
Прод-источник логики: [sber-invest.kz/services/taxreturn/test](https://sber-invest.kz/services/taxreturn/test)

## Решение

Выбрана **концепция #3 — «Сканер сигнала»** (оболочка для стенда).

| Цель | Концепция |
|------|-----------|
| Вирусность | 1. Инспектор на хвосте |
| Доверие + конверсия | 2. Окно дедлайна |
| **Быстрый mobile MVP / стенд** | **3. Сканер сигнала** ← катим |

- Дерево вопросов и **8 юридических исходов не менять**
- Меняется только оболочка: радар, 3 волны, Threat Level, финалы CLEAR / WATCH / ALERT / OUT
- Эмоция «Поймали вовремя. У тебя есть план» — только на WATCH / ALERT

## Как катить #3 на стенд

1. Старт: радар + кнопка **«Сканировать»**
2. Три волны: Резидент → Обязательные → Активы
3. Threat Level сверху
4. Финалы: CLEAR / WATCH / ALERT / OUT OF SCOPE
5. Поражение только при броске скана → «Скан не завершён» + рестарт за 1 тап

Подробности, маппинг исходов, Δ Threat, копирайт и критерии приёмки — в спеке #3.
